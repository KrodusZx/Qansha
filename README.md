# Qansha? 3.0 — минималистичный поиск поездок

Упрощённая мобильная версия Qansha? с тремя самостоятельными вкладками: **Авиабилеты**, **Отели**, **Бюджет**.

## Что обновлено

- Убрана длинная подборка из 51 города с главной страницы. Аэропорты и города выбираются по поиску, включая международные направления.
- API автодополнения `/api/locations` использует публичную базу аэропортов OpenFlights с IATA-кодами по всему миру (с резервным CDN); подсказки по некоторым городам на русском, по остальным — на английском. Это не исчерпывающий список всех населённых пунктов: для поиска авиабилетов нужен аэропорт или городской IATA-код.
- Поля дат адаптированы для мобильного экрана; больше нет наложения полей друг на друга.
- Выбор даты в отдельном календаре; после открытия запрашиваются **минимальные найденные цены на 7 дней**, если для выбранного маршрута доступен источник данных. Для ручной повторной проверки есть кнопка. Пустая стоимость не значит, что билетов нет.
- Поиск и сортировка авиабилетов по цене, выбор рейса, избранное. Если поставщик не дал цену, показывается ссылка на Google Flights, а не выдуманный тариф.
- Отели вынесены в отдельную вкладку; конкретные названия и ориентировочные цены на группу, автоматический выбор эконом / средний / комфорт из найденных гостиниц.
- Бюджет — отдельная вкладка. Итог строится только с выбранными билетами и отелем; на месте расходы регулируются ползунком.
- Email-аккаунт через Supabase при наличии публичных настроек; иначе избранное хранится локально на устройстве.

## Размещение

Проект развертывается через Vercel из GitHub. `index.html`, `app.js`, `styles.css`, `config.js`, `api/search.js`, `api/locations.js`, `vercel.json` должны находиться в корне репозитория (API в подпапке `/api`).

**Секрет:** `SERPAPI_API_KEY` — задайте как `Secret` в Vercel → Project → Settings → Environment Variables → Production и выполните новый Deploy. **Никогда** не помещайте ключ SerpApi в GitHub, HTML или `config.js`.

Сервер `/api/search` работает с Google Flights и Google Hotels через SerpApi. Бесплатный лимит может быстро закончиться: запрос билетов туда-обратно вызывает несколько запросов, а календарь может выполнять до 7 запросов при открытии. Цены недолговечны, могут отсутствовать по отдельным датам и не гарантируют возможность покупки. Для группы тариф перелёта рассчитан из предложения на одного взрослого; не считается подтверждённой ценой для всех. Багаж нужно проверять отдельно.

Для облачного избранного и входа зарегистрируйте проект Supabase, выполните `supabase/schema.sql`, укажите публичные `supabaseUrl` и `supabaseAnonKey` в `config.js` и разрешите URL вашего сайта в Authentication → URL Configuration. Приватный Supabase service_role key запрещено добавлять в frontend.

## Данные и атрибуция

Поиск аэропортов использует [OpenFlights Airports Database](https://openflights.org/data.html) (Open Database License, ODbL 1.0) из репозитория [jpatokal/openflights](https://github.com/jpatokal/openflights). База — периодически обновляемый статический список аэропортов, **не** источник текущего расписания.
